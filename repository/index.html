PixInsight repository

PixInsight scripts

Free scripts for PixInsight, installed and kept up to date by PixInsight itself.

Add the repository

  1. In PixInsight, open Resources › Updates › Manage Repositories.
  2. Press Add, enter this address and press OK: https://pixinsight.blastrophoto.com/
  3. Open Resources › Updates › Check for Updates, apply the updates and let PixInsight restart. The scripts appear in the Script menu.

From then on, Check for Updates brings each new version.

Not signed yet. The scripts are waiting for their PixInsight developer signature. Until then PixInsight may warn that the repository is not signed when it checks for updates: accept to go on. If a script then will not run, tick Allow execution of unsigned scripts under Edit › Preferences › Security.

The scripts

ContinuumTools 1.2.0

Script › ContinuumTools · released 2026-11-13

Narrowband Continuum Subtraction takes the continuum out of Hα, OIII or SII without leaving black star holes. Broadband Line Removal takes the emission-line light out of R, G and B, leaving dust, reflection nebulae and stars. Star Hole Repair fills the dark holes that over-subtracted stars left in an existing image. Add Narrowband to RGB blends stretched Hα, OIII and SII into a stretched RGB image with a soft addition that never clips, and can add a line's brightness and its cleaner fine detail to the lightness alone, without more colour.

Needs PixInsight 1.9.4 or later. StarXTerminator (RC Astro), when it is installed, makes the starless copies.

Synthetic NB Luminance 1.5

Script › Utilities · released 2026-11-12

Combines two or more registered narrowband masters into one luminance master, weighting each pixel by where each filter really has signal, so faint Hα is not diluted by empty OIII and faint OIII is not buried by bright Hα.

Run it on linear, registered, identically cropped masters.

The scripts make no network connections and start no other programs. Their sources, notes and history are on GitHub.
